# **노션 사이트(Notion Sites) 기반 인터랙티브 웹 포트폴리오 제작 교안 및 딥리서치 가이드**

## **1\. 3시간 완성을 위한 포트폴리오 기획 및 핵심 프레임워크**

디지털 환경에서의 웹 포트폴리오는 개인의 정체성과 직무적 역량을 시각적으로 증명하는 전략적 웹사이트로 기능한다1. 지원자의 첫인상을 결정짓는 채용 현장에서 평가자는 수많은 포트폴리오를 빠르게 스캐닝하므로, 정보의 전달력과 구조적 명확성이 선결되어야 한다3. 직무 연관성을 높이고 가독성을 극대화하기 위해 포트폴리오의 첫 화면 및 세부 구성은 프로필, 경력 사항, 대표 프로젝트, 핵심 스킬, 그리고 외부 연동 채널의 5대 핵심 섹션으로 진열된다3.  
프로필 영역은 개개인의 핵심 가치를 요약한 한 줄 슬로건과 함께 직무 타이틀, 프로필 이미지, 주요 연락처로 채워진다3. 경력 사항 섹션에서는 역순(최신순) 정렬을 원칙으로 하여 소속 조직, 담당 직무, 연도별 주요 과업 및 정량적 성과를 명시한다3. 핵심 스킬 섹션은 단순히 소프트웨어 아이콘을 열거하는 수준을 넘어, 활용 가능 수준과 실제 업무 적용 사례를 구체적 텍스트로 기술하는 것이 채용 담당자의 신뢰를 얻는 데 유리하다3.

| 섹션 구분 | 필수 포함 요소 | 작성 전략 및 구조화 가이드라인 |
| :---- | :---- | :---- |
| **Profile** | 한 줄 슬로건, 프로필 이미지, 연락처, 주요 링크 | 지원자의 직무적 정체성을 드러내는 5줄 이내의 간결한 요약문 배치3 |
| **Experience** | 학력, 근무 경력, 인턴십, 주요 수상 이력 | 최신순 배치 및 지원 직무와 직결되는 성과 지표(%) 명시3 |
| **Projects** | 프로젝트명, 수행 기간, 기여도, 메인 스택, 성과 | 직무 연관성이 가장 높은 대표 사례 3\~5개를 선별하여 카드로 배치3 |
| **Skills** | 활용 가능 툴, 직무 전문 역량, 레벨 | 단순 별점 방식 대신 구체적 작업 가능 범위를 정성·정량적으로 서술3 |
| **Contact** | 이메일, GitHub, LinkedIn, Behance, SNS | 클릭 시 해당 플랫폼으로 즉시 연결되는 하이퍼링크 및 버튼 구성3 |

프로젝트 세부 사례를 작성할 때는 결과물만을 보여주는 정적 방식을 지양하고, 작업자의 논리적 사고 과정과 문제 해결 역량을 입증할 수 있는 PAR-R(Problem-Action-Result-Retrospective) 프레임워크를 적용한다3. 문제 정의 단계에서는 정량적 데이터나 유저 인터뷰를 바탕으로 해결해야 할 과제를 3줄 이내로 명확히 명시한다3. 수행 행동 단계에서는 본인의 실제 기여도와 핵심 설계, 개발, 기획 로직을 구조화한다3. 결과 단계에서는 전환율, 조회수, 공정 단축 비율 등 정량 지표를 기반으로 성과를 증명하며, 마지막 회고 단계에서는 프로젝트를 통해 얻은 레슨스 러인드(Lessons Learned)와 추후 개선점을 서술하여 성장 가능성을 어필한다3.  
단 3시간이라는 한정된 강의 시간 내에 완성도 높은 포트폴리오를 기획하기 위해서는 텍스트 작성의 병목을 줄이는 스크리닝 매트릭스가 필요하다. 수강생은 사전에 준비해 온 경험 자산 데이터를 시트에 나열한 뒤, 지원 직무에 적합한 항목만을 선별한다. 작성 시에는 문장의 어미를 명사형으로 통일하여 비즈니스 문서로서의 전문성을 확보하고4, 중요한 시각적 키워드나 숫자는 서식을 활용해 강조한다4. 긴 본문으로 인한 스크롤 피로를 방지하기 위해 메인 화면은 요약 카드로 노출하고, 상세 내용은 클릭 시 열리는 하위 페이지로 분리하는 정보 계층 설계를 채택한다3.

## **2\. 노션 공식 템플릿 분석 및 커스터마이징 전략**

노션 마켓플레이스 및 공식 갤러리에서 제공하는 웹 포트폴리오 템플릿은 목적과 직무군에 따라 구조적 특징이 상이하다1. 개인 포트폴리오 템플릿은 단일 랜딩페이지 레이아웃을 기반으로 하여 초보자가 빠르게 커스터마이징하기에 적합하다1. 디자이너 및 개발자용 템플릿은 메인 화면에 갤러리 데이터베이스를 배치하여 시각적 작업물 커버를 먼저 노출시키는 구조를 취한다5. 에이전시형 포트폴리오 템플릿은 히어로 섹션, 클라이언트 로고, 서비스 프로세스 등 신뢰도를 극대화하는 요소들로 구성된다10.  
웹 포트폴리오의 전체적인 레이아웃 체계는 최상단에 홈, 소개, 프로젝트, 연락처로 이동할 수 있는 내비게이션 바가 위치하며, 그 아래로 프로필 이미지와 한 줄 슬로건이 포함된 히어로 섹션이 배치된다. 중앙 본문에는 프로젝트 갤러리 데이터베이스가 그리드 형태로 정렬되며, 하단에는 경력 사항 표와 스킬 태그 모음이 들어간다. 최하단 푸터 영역에는 동기화 블록을 활용한 저작권 표시 및 외부 채널 링크가 일관되게 적용된다.  
템플릿을 선택할 때는 가독성과 로딩 속도를 해치지 않는 미학적 절제미가 요구된다1. 지나치게 복잡한 다단 구조나 외관 꾸미기용 위젯의 과다 사용은 웹페이지의 로딩 속도를 저하시키고 방문자의 집중을 방해하므로 지양해야 한다1. visual clarity를 확보하기 위한 디자인 원칙으로 브랜드 테마 컬러는 메인, 서브, 포인트의 3가지 톤 이내로 제한하고4, 제목 계층(H1, H2, H3)을 엄격히 준수하며, 여백과 콜아웃 블록을 적극 활용하여 시각적 피로도를 최소화한다4.  
노션의 자체 웹 배포 엔진인 노션 사이트(Notion Sites)는 클릭 몇 번으로 작성 중인 페이지를 고유한 웹사이트로 전환한다11. 게시 설정 창에서 제공하는 커스터마이징 옵션을 적절히 활용하면 플랫폼 독립적인 전문 웹사이트의 형태를 구축할 수 있다12.

| 게시 커스텀 옵션 | 기능 및 제공 혜택 | 실무 적용 및 최적화 전략 |
| :---- | :---- | :---- |
| **Site Slug** | 기본 URL 뒤의 고유 하위 주소 변경 (.notion.site/my-name)14 | 지원자 이름이나 퍼스널 브랜딩명을 반영한 직관적 URL 생성14 |
| **Theme** | Light 모드, Dark 모드, 시스템 설정 모드 제어12 | IT·개발 직무는 다크 테마, 기획·디자인은 라이트 테마 등 콘셉트 반영13 |
| **Favicon & Thumbnail** | 브라우저 탭 아이콘 및 소셜 링크 공유 썸네일 업로드12 | 메시저 공유 시 브랜드 로고와 대표 작업물이 노출되도록 세팅13 |
| **Header Options** | 이동 경로(Breadcrumbs), 검색, 템플릿 복제 토글12 | 내비게이션 편의성을 향상시키고 템플릿 무단 복제를 방지13 |
| **Search Engine Indexing** | 구글 등 웹 검색 엔진 노출 여부 선택12 | 범용 공개 시 Indexing On, 제출용 비공개 시 Indexing Off 세팅13 |
| **Google Analytics** | GA 추적 ID 연결을 통한 방문자 데이터 분석12 | 포트폴리오 유입 경로 및 섹션별 체류 시간 지표 추적13 |

## **3\. 멀티미디어 및 동적 인터랙션 페이지 구성 기법**

단순한 텍스트 기반의 문서에서 벗어나 방문자와의 상호작용을 유도하는 웹 포트폴리오를 제작하기 위해서는 외부 서비스 임베드와 노션 고유의 동적 블록을 적극적으로 결합해야 한다12. /임베드 명령어를 사용하면 Figma의 프로토타입 시연 화면, YouTube 인터뷰 영상, Loom을 통한 사업 기획 발표, Google Drive 문서 및 PDF 파일 등을 페이지 내부에서 직접 작동하는 형태로 삽입할 수 있다4. 이러한 미디어 임베드는 방문자가 외부 사이트로 이탈하지 않고 포트폴리오 내부에서 작업물을 다각도로 검증할 수 있도록 돕는다4.  
포트폴리오의 사용자 경험(UX)을 향상시키는 핵심 요소로 동기화 블록(Synced Block)과 버튼(Button) 블록이 활용된다19. 여러 하위 페이지에 공통으로 적용되는 최상단 내비게이션 바나 최하단 저작권 푸터 영역을 동기화 블록으로 지정하면, 원본 블록 단 한 곳의 수정만으로 연결된 모든 하위 페이지의 메뉴가 자동 업데이트된다19. 또한 노션의 버튼 블록을 활용하면 클릭 한 번으로 이메일을 바로 발송하거나, PDF 이력서를 즉시 다운로드하고, 페이지 최상단으로 이동하는 CTA(Call-To-Action) 인터랙션을 구현할 수 있다.  
프로젝트 아카이빙 시 구식 리스트 형태를 대체하는 데이터베이스 갤러리 뷰는 정돈된 시각적 그리드를 제공한다5. 데이터베이스 속성(Property) 설정을 통해 직무 구분 태그, 진행 기간, 담당 역할, 주요 성과, 커버 이미지를 구조화하여 관리한다3.  
갤러리 카드의 시각적 매핑은 카드 피드백(Card Preview) 옵션을 '페이지 커버' 또는 지정된 '파일 및 미디어' 속성으로 선택하여 완성한다5. 카드 표면에는 프로젝트 제목, 주요 태그(\#UI/UX, \#Figma), 기간(2024.03 \~ 2024.05), 핵심 성과(전환율 \+145% 상승) 등이 노출되도록 속성 표시 토글을 제어하며, 필터 및 정렬 기능을 적용하여 특정 직무용 프로젝트만 선별 노출하거나 최신순으로 정렬되도록 세팅한다3.

Module 4에서는 노션 사이트 배포 탭에서 '웹에 게시' 버튼을 누르고 슬러그 주소를 지정하는 과정을 동시 진행한다12. 1일차 수업 종료 전 수강생 전원의 1차 URL 생성을 확인하여 퍼블리싱 환경을 확립한다12.

## **5\. 목요일(2일차) 목요일 3시간 교안 가이드: 동적 페이지 구성 및 초안 완성**

Module 8에서는 배포된 웹 포트폴리오의 접근 권한 오류를 방지하기 위해 시크릿 모드 검수를 필수로 진행하고, 완성된 웹 포트폴리오 URL을 상호 공유하며 교안 실습을 마무리한다3.

## **6\. 최종 산출물 검수 및 시크릿 모드 배포 체크리스트**

노션 사이트를 웹에 최종 배포하기 전, 수강생은 작성된 웹 포트폴리오가 외부 방문자에게 오류 없이 전달되는지 검증하는 품질 보증(QA) 절차를 거쳐야 한다3. 검수 파이프라인은 먼저 노션 사이트 웹 게시를 활성화한 후, 로그인 정보가 없는 시크릿 모드에서 외부 권한 및 링크 연결을 체크한다3. 이어서 모바일 디바이스 뷰에서의 반응형 정렬을 확인하고, 문장 어미 및 오타 교정을 진행한 뒤, 마지막으로 파비콘, 소셜 썸네일, Google Analytics 추적 설정을 마치는 5단계 순서로 완성된다3.

| 검수 영역 | 세부 점검 항목 | 통과 기준 및 조치 가이드 |
| :---- | :---- | :---- |
| **1\. 외부 접근 권한** | 로그인하지 않은 외부인도 페이지 조회가 가능한가? | 브라우저 시크릿 창(Ctrl+Shift+N) 접속 시 로그인창 없이 즉시 노출3 |
| **2\. 하위 페이지 열람** | 메인 페이지 내의 프로젝트 상세 페이지가 정상적으로 열리는가? | 상위 페이지 배포 시 하위 페이지 공유 권한이 동시 적용되었는지 확인13 |
| **3\. 모바일 반응형 레이아웃** | 모바일 디바이스에서 레이아웃이나 이미지가 깨지지 않는가? | 모바일 세로 뷰에서 텍스트 잘림 현상이나 수평 스크롤 없이 정상 배치2 |
| **4\. 외부 하이퍼링크 작동** | 외부 링크(Figma, GitHub, PDF, 이메일)가 제대로 동작하는가? | 클릭 시 새 탭에서 해당 사이트로 바로 이동하거나 이메일 앱 실행3 |
| **5\. 무단 복제 방지** | 방문자가 내 포트폴리오를 자신의 노션으로 복제하지 못하게 막았는가? | 노션 사이트 설정에서 '템플릿으로 복제 허용' 토글을 비활성화(Off)12 |
| **6\. 비주얼 브랜딩** | 카카오톡, 링크드인 등 링크 공유 시 썸네일과 파비콘이 노출되는가? | 사이트 맞춤 설정에서 Favicon 및 Header Thumbnail 이미지를 지정12 |
| **7\. 텍스트 및 가독성** | 오타가 없으며 비즈니스용 어미가 잘 적용되었는가? | 명사형 어미('분석 완료', '기획 수립') 통일 및 텍스트 서식 검수3 |

이와 같은 체계적인 검수 절차를 거친 노션 웹 포트폴리오는 단독 웹사이트 URL 형태로 채용 플랫폼에 제출되거나, PDF 이력서 상단의 대표 링크로 결합되어 지원자의 구직 경쟁력과 디지털 실무 역량을 입증하는 최종 산출물로 완성된다1.
