# 2차시
# NotebookLM으로 시작하는 자료 기반 AI 문서 작성

### 핵심 흐름

> **내 자료를 넣는다 → AI가 읽는다 → 질문한다 → 정리한다 → 문서로 만든다**

---

# 01. 오늘은 AI를 '공부'하지 않는다

## 오늘의 목표

1차시에서는

> **AI가 어떻게 작동하는가?**

를 배웠다면,

2차시에서는

> **AI에게 내 업무를 어떻게 맡길 것인가?**

를 경험한다.

### 오늘의 핵심

**NotebookLM을 배우는 것이 목적이 아니다.**

### 목적은

> **내가 가지고 있는 자료를 AI와 함께  
> 업무에 활용하는 방법을 익히는 것**

---

# 02. NotebookLM이란?

## 한 문장으로

> **내가 제공한 자료를 중심으로  
> 읽고, 찾고, 비교하고, 정리해주는 AI 연구·사고 도구**

NotebookLM은 일반적인 생성형 AI와 달리  
사용자가 제공한 소스를 중심으로 질문하고 답변하며,  
답변의 근거가 되는 출처를 확인할 수 있도록 해준다.

### 쉽게 말하면

# “내 자료를 읽어주는 AI 비서”

---

# 03. 일반 생성형 AI와 무엇이 다른가?

## ChatGPT / Gemini 같은 범용 AI

```text
질문
 ↓
모델
 ↓
생성
```

## NotebookLM

```text
내 자료
 ↓
Notebook
 ↓
자료를 기반으로 질문
 ↓
근거 중심 답변
```

### 핵심 차이

**범용 AI에게**

> “이 주제에 대해 알려줘.”

라고 묻는 것과

**NotebookLM에게**

> “내가 제공한 자료를 기준으로 알려줘.”

라고 묻는 것은 다르다.

### 오늘 기억할 말

> **범용 AI는 '무엇이든 묻는 AI'라면  
> NotebookLM은 '내 자료를 중심으로 묻는 AI'다.**

---

# 04. 1차시에서 배운 RAG와 연결하기

## NotebookLM을 이해하면
## RAG가 훨씬 쉽게 보인다.

1차시에서 배운 구조

```text
질문
 ↓
관련 정보 검색
 ↓
Context 확보
 ↓
생성
```

NotebookLM의 기본적인 사용 경험도

```text
내 자료
 ↓
관련 내용 찾기
 ↓
Context
 ↓
AI 답변
```

의 흐름으로 이해할 수 있다.

### 그래서

> **NotebookLM은 “자료 기반 AI”를  
> 직접 체험해 보는 좋은 도구**

라고 설명하면 된다.

---

# 05. NotebookLM의 기본 구조

## 화면을 세 부분으로 기억한다.

### Sources
**무엇을 읽게 할 것인가?**

### Chat
**무엇을 물어볼 것인가?**

### Studio
**무엇을 만들어낼 것인가?**

---

## 한눈에 보기

```text
┌────────────┬──────────────┬──────────────┐
│  Sources   │     Chat     │    Studio    │
│            │              │              │
│ 자료 관리  │ 질문·대화     │ 결과물 생성   │
│ 자료 추가  │ 분석·정리     │ 노트·보고서   │
└────────────┴──────────────┴──────────────┘
```

### 기억하기

> **Sources = 자료**  
> **Chat = 질문**  
> **Studio = 결과물**

---

# 06. 어떤 자료를 넣을 수 있을까?

## NotebookLM의 강점은
## 여러 자료를 한곳에 모아 활용하는 것이다.

대표적으로

- PDF
- Word
- Markdown / TXT
- 웹페이지
- Google Docs
- Google Slides
- 공개 YouTube 영상
- 오디오 파일
- CSV 등

다양한 자료를 소스로 활용할 수 있다.

### 사회복지사의 업무로 바꾸어 생각하면

```text
사업계획서
+
운영일지
+
결과보고서
+
만족도 조사
+
회의록
+
기관 양식
+
관련 지침
```

이 자료들을 하나의 Notebook에 모아두면,

> **“이 사업에 대해 자료를 모두 알고 있는  
> AI 업무 공간”**

처럼 활용할 수 있다.
