사내 보안 규정과 AI 활용 경계

회사 내부의 경영 지표나 개인정보가 포함된 엑셀 파일을 외부 퍼블릭 AI에 직접 업로드하는 것은 사내 보안 가이드라인 위반이 될 수 있습니다. 따라서 데이터를 노출하지 않고도 안전하게 결과를 얻는 우회 전략을 설계해야 합니다.

프롬프트의 구성 요소

좋은 답변을 유도하는 구조화 프롬프트는 아래와 같이 크게 세 가지 핵심 블록(지시문, 맥락, 지침)으로 구성됩니다. 기아 최초의 정통 픽업트럭 'The 2027 타스만' 계약 개시 홍보 뉴스레터 작성 시나리오를 통해 그 구조를 살펴보겠습니다.

기아 최초의 정통 픽업트럭인 'The 2027 타스만'과 신규 '오픈베드' 모델의 계약 개시 소식을 알리고 혜택을 안내하는 홍보용 이메일 뉴스레터를 작성하십시오.
차량명은 The 2027 타스만이며, 기아 최초의 정통 바디 온 프레임 방식 픽업트럭입니다.
차량의 주요 특징은 다음과 같습니다:
- 강력한 오프로드 성능과 동급 최고 수준의 3.5톤 견인력을 자랑합니다.
- 2026년 7월 초부터 신규 적재 편의 사양인 '타스만 오픈베드' 모델 계약이 공식 개시되었습니다.
- 프리미엄 공구 브랜드 밀워키(Milwaukee)와 협업한 전용 오프로드 및 적재함 커스터마이징 용품이 운영됩니다.
브랜드는 도전과 혁신의 가치를 담은 기아(KIA)이며, 주요 타깃은 아웃도어 레저를 즐기는 30~50대 개인 고객 및 견인 성능이 필요한 비즈니스 고객입니다.
다음 사항을 반영하여 작성하십시오:
- 뉴스레터 제목 1개와 본문 문구를 작성하십시오.
- 본문은 800자 이내로 작성하고, 역동적이면서도 신뢰감을 주는 서술형 어조로 작성하십시오.
- 타스만의 핵심 셀링 포인트인 '3.5톤 견인력', '오픈베드 사양 추가', '밀워키 협업 커스텀 용품'을 반드시 포함하십시오.
- 본문의 마지막은 공식 계약 문의 및 지점 방문을 유도하는 Call to Action(클릭 버튼 문구)으로 마무리하십시오.

엑셀 전용 구조화 프롬프트 3요소

Task (작업)

AI가 수행할 궁극적인 목적입니다. 엑셀 실무에서는 단 세 가지만 정의하면 충분합니다.

1. 수식(함수식) 요청
2. 기능/동작 사용법
3. VBA 코드 생성

Context (데이터 묘사)

원본 파일을 올리지 않으므로, 데이터의 생김새를 말해줍니다.

- 데이터의 셀 범위
- 행의 정보
- 열의 정보
- 첫 행의 머리글(Header) 여부
- 데이터 타입(수치형/문자형)

Instruction (지침)

답변을 생성할 때 반드시 따라야 할 제약 조건과 출력 형태입니다.

- 사내 엑셀 버전 명시 (예: Excel 2021)
- 중복 제거 여부
- 특정 예외값 처리 지시

📝 마크다운(Markdown)이란?

마크다운은 일반 텍스트에 간단한 기호(#, *, -, 등)를 추가하여 서식(제목, 볼드, 목록 등)을 입히는 가벼운 마크업 언어입니다. AI에게 질문할 때 마크다운 기호를 사용하면 요청사항의 구조(제목, 본문, 목록, 구분선)가 명확히 분리되므로, AI가 지시사항과 데이터를 헷갈리지 않고 정확히 인지하게 해주는 핵심적인 프롬프팅 도구입니다.

마크다운 특수 기호 테이블

  • 일반적인 텍스트 문서를 서식이 있는 문서로 변환하도록 설계된 문법입니다.
  • 직관적이고 HTML로 변환되며 다양한 플랫폼에서 사용 가능하므로 구조화된 프롬프트 작성에 널리 활용됩니다.

💡 엑셀 프롬프트 작성 시 부담 줄이기

최신 생성형 AI 모델들은 문맥 파악 능력과 복원력이 매우 뛰어납니다. 따라서 마크다운 형식이나 괄호 표기법을 완전히 수학적으로 엄격하게 준수하지 않더라도, 대략적인 형태와 의도만 명확하게 전달되면 AI가 찰떡같이 알아듣고 정상 수식을 만들어 줍니다. 형식을 반드시 정확하게 작성해야 한다는 부담은 내려놓으셔도 괜찮습니다.

마크다운 형식 테스트용 프롬프트
아래 마크다운(Markdown) 텍스트를 그대로 읽고, 지시사항에 따라 결과를 화면에 출력해 주십시오. # [테스트 제목] 마크다운 가독성 테스트 --- ## 1. 주요 특징 - **볼드체**: 이 텍스트는 굵게 표시되어야 합니다. - *이탤릭체*: 이 텍스트는 기울임꼴로 표시되어야 합니다. ## 2. 지시사항 위 구조화된 마크다운의 형식을 유지한 채, 각 항목의 텍스트 뒤에 "확인 완료"라는 문구를 붙여서 코드 블록(` `) 형식이 아닌 일반 텍스트 형식으로 깔끔하게 변환하여 출력해 주십시오.

💡 개념 정의: 데이터 업로드 차단 우회 및 데이터 구조 설명법

보안 규정상 실무 데이터를 올릴 수 없을 때, 우리는 엑셀 시트 내 데이터의 구조(Context)만을 논리적으로 묘사하여 원하는 정확한 함수식을 추출해낼 수 있습니다. AI는 실제 행과 열에 채워진 데이터가 없더라도, 설명된 범위와 열의 구조적인 관계만 파악하면 알맞은 정답 수식을 계산해 줍니다.

차종별 최대 판매량(MAX) 수식 도출용 프롬프트 (원클릭 복사 가능)
#Task: 엑셀 함수식을 알려주십시오. #Context: - 데이터의 범위: D5:O18 - 행: 기아 주요 차종별 글로벌 판매 실적 - 열: Jan. Feb. Mar. Apr. May. Jun. Jul. Aug. Sep. Oct. Nov. Dec. - 머릿글: 5번 행은 머릿글 - 데이터 타입: 모두 수치형 #Instruction: - 엑셀 2021을 기준으로 제안해주십시오. - 각 행의 최대값을 구하는 수식
💡 엑셀 2021 버전 지정을 하는 이유

최신 엑셀 버전에서 사용 가능한 UNIQUE, FILTER, XLOOKUP 함수 등은 하위 버전(2016 등)에서 작동하지 않고 오류가 발생합니다. 사내 환경이 2021 버전이라면 지침에 반드시 버전을 기재해 하위 호환성을 가진 기본 함수 조합(INDEX, MATCH, MIN, MAX 등)으로 유도해야 합니다.

2-4. AI 수식 오류 해결법 및 우회 대응

AI 수식이 동작하지 않을 때의 단계별 대처법

AI가 만능은 아닙니다. 데이터 구조 설명을 잘했더라도 엑셀 수식 작성 과정에서 오류가 발생해 셀에 #N/A, #VALUE!, #NAME? 에러가 찍히는 경우가 빈번합니다. 이럴 때는 당황하지 않고 아래의 디버깅 지침에 맞춰 AI에게 상황을 다시 피드백해 주어야 합니다.

⚠️ 자주 발생하는 3대 엑셀 오류 코드와 AI 대처 요령
  • #N/A (값 없음): 주로 VLOOKUP/XLOOKUP/INDEX-MATCH 수행 시 찾으려는 값이 대상 범위에 없을 때 발생합니다. 데이터 형식의 불일치(숫자형 텍스트 vs 실제 숫자)가 주요 원인이므로 AI에게 "조회하려는 데이터와 원본 테이블 데이터의 형식을 일치시켜 주는 수식으로 제안해줘"라고 요구해야 합니다.
  • #VALUE! (값 오류): 텍스트와 숫자를 같이 계산하거나 잘못된 범위 인수를 결합할 때 발생합니다. AI에게 "데이터 중에 공백(Space)이나 빈 셀이 포함되어 있어도 오류를 내지 않고 공백으로 처리하는 예외 처리 수식으로 보강해줘"라고 지시하십시오.
  • #NAME? (함수명 오류): 엑셀 버전이 낮아 AI가 제안한 최신 함수(예: XLOOKUP, FILTER, UNIQUE)를 내 엑셀 버전에서 인식하지 못할 때 발생합니다. 즉시 "내가 쓰는 엑셀 버전은 2016 버전이야. XLOOKUP 대신 INDEX와 MATCH, 또는 VLOOKUP을 조합한 대체 수식을 알려줘"라고 피드백하십시오.

1단계: 수식 오류 상황 피드백 프롬프트

에러가 난 수식과 오류 코드를 그대로 복사해서 AI에게 원인 분석 및 수정을 요청하는 프롬프트 양식입니다.

수식 오류 상황 피드백 프롬프트
제안해 준 수식을 셀에 입력했더니 #N/A 에러가 발생했습니다. 입력한 수식: [=INDEX(B2:B21, MATCH(G2, A2:A21, 0))] 조회 조건 데이터(G2)는 숫자로 보이지만, 원본 범위(A2:A21)는 텍스트 형식으로 저장된 것 같습니다. 데이터 형식 불일치 문제를 예방할 수 있도록, 조회 데이터(G2)에 VALUE 함수나 TEXT 함수를 결합하여 형식을 맞춘 개선 수식으로 다시 제안해 주세요.

2단계: 엑셀 버전 대체 수식 요청 프롬프트

최신 함수인 XLOOKUP을 미지원하는 구버전 엑셀(Excel 2016/2019) 사용 시, 하위 호환 가능한 대체 수식을 유도하는 양식입니다.

엑셀 구버전 대체 수식 요청 프롬프트
제안해 준 수식에 XLOOKUP 함수가 포함되어 있습니다. 제가 현재 사용하는 엑셀은 365 버전이 아닌 오피스 2016 버전입니다. 따라서 XLOOKUP 함수는 인식되지 않아 #NAME? 에러가 납니다. 엑셀 2016 버전에서 동작 가능하도록 XLOOKUP 대신 INDEX와 MATCH, 혹은 VLOOKUP 함수를 조합한 동일 기능의 대체 수식을 알려주세요.

여러 개의 함수(INDEX, MATCH, SEARCH, IFERROR 등)가 복잡하게 얽혀 셀에 길게 적힌 수식은 유지보수가 매우 힘듭니다. 이럴 때 VBA 모듈에 사용자 정의 함수(User Defined Function, UDF)를 정의해 두면, 일반 수식 창에서 =my_engine(A2) 처럼 간단하게 수식을 적을 수 있습니다.

UDF 사용자 정의 함수 생성용 프롬프트
엑셀 사용자 정의 함수를 만드는 VBA 코드를 작성해주십시오. #함수 - 형태: =my_engine(옵션명,분류) -기능: ‘옵션명’에 있는 텍스트에 ‘분류’에 있는 항목이 포함되어 있다면, 해당 항목들을 추출한다. - 출력: 쉼표로 구분 #지침 - 엑셀 2021에서 잘 동작해야 합니다.
✏️ 엑셀 UDF 사용 예시

VBA 모듈에 함수를 선언해 둔 뒤, 엑셀 셀 창에 다음과 같이 간결하게 입력합니다:

=my_engine(A2, $F$2:$F$6)

4-4. VBA 실행 에러 분석 및 AI 디버깅

VBA 런타임 에러 대처 및 노란색 디버그 줄 수정 요청법

VBA 매크로 코드는 엑셀 함수보다 훨씬 복잡하며, 시트 이름의 오타, 병합된 셀, 또는 데이터 범위 오버플로우로 인해 '런타임 오류'가 쉽게 발생합니다. 매크로 실행 중 에러 창이 떴을 때 AI를 활용해 즉각적으로 해결하는 실무 디버깅 요령을 설명합니다.

💡 VBA 에러 발생 시 디버깅의 정석 3단계
  1. 에러 창의 오류 메시지 복사: "런타임 오류 '1004': 정의한 응용 프로그램 또는 개체 정의 오류입니다" 같은 메시지를 텍스트로 그대로 기억하거나 캡처합니다.
  2. [디버그] 버튼 클릭 후 노란색 줄 확인: 에러 창에서 [디버그(Debug)] 버튼을 누르면 VBA 에디터 창(VBE)이 열리며 에러가 발생한 코드 라인이 **노란색**으로 하이라이트됩니다.
  3. AI에게 코드 전체와 노란색 줄 피드백: AI에게 "이 코드에서 노란색 하이라이트된 부분에서 런타임 오류가 발생했어. 수정해줘"라며 피드백을 전달합니다.

1단계: VBA 런타임 에러 피드백 프롬프트

VBA 코드 실행 오류 상황과 노란색 디버깅 포인트를 AI에게 전달하여 해결 코드를 얻어내는 프롬프트 양식입니다.
