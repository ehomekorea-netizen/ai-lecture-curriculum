# Lecture Deck Kit

Reusable Slidev starter kit for Korean lecture decks.

The visual anchor is the latest VueConf deck in the local talks repository. The kit keeps the dark minimal stage, large type, restrained glow, Iconify SVG icons, fade-out transitions, and staged reveals while leaving the content and teaching flow open.

## Use

1. Start with references/trigger-workflow.md and run ANALYZE.
2. Confirm the slide sequence and visual cues with APPROVE.
3. Generate the lesson-specific slides.md with BUILD.
4. Run QA and fix visual issues before publishing.

This staged workflow is intentional: a reusable kit fixes the visual language, while the lesson flow and asset choices remain reviewable before code generation.

The included slides.md is a working visual sampler, not a finished lesson.

## Creation contract

- The deck target is Slidev web presentation.
- The user supplies audience, duration, learning outcome, rough flow, and asset priorities.
- The agent chooses exact slide count, copy, layout, icons, crops, and reveal order.
- When only assets are provided, create an asset inventory and outline proposal first.
- Do not invent claims, numbers, sources, or policies.
- Review three representative slides before expanding a long deck.
